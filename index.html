A photo pipeline that stays home

In short

What is FlipsiColor?

FlipsiColor is a free, open-source photo and video editor (GPL-3.0) for Windows and Linux that corrects, restores and enhances images using AI models that run entirely on your own computer. It reads RAW files from Canon (CR2/CR3), Nikon (NEF), Sony (ARW) and generic DNG, applies lens correction via Lensfun, grades videos frame by frame with scene detection, upscales images up to 4x with RealESRGAN, restores faces with CodeFormer and brightens dark shots with automatic low-light enhancement. All AI models run offline on the user's own hardware — no upload, no account, no subscription.

FAQ

Common questions

Does it upload my photos anywhere? No. Corrections run on your own hardware. The only network traffic is the one-time download of the AI models from the project's GitHub Releases.

Is it really free? Yes, free and open source under GPL-3.0. There is no paid tier, watermark or usage limit.

Which file types are supported? JPEG, PNG, WebP and common RAW formats (CR2, CR3, NEF, ARW, DNG) for photos; common video formats for grading with preserved audio.

Do I need a powerful GPU? No. The CPU-mode handles the pipeline; an NVIDIA/AMD GPU only speeds the AI steps up.

How is it different from Darktable or Lightroom? Those are manual editors with full control per slider. FlipsiColor automates the correction with AI and stays fully offline — a complement, not a replacement.

Context

Where it fits

Cloud AI editors. Convenient, but your photos travel to someone else's server — often with compression and subscription fees.
