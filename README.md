# FlipsiColor

Landing page & documentation hub for **FlipsiColor**, a free, open-source AI photo and video color correction application for Windows and Linux.

Live site: https://techflipsi.github.io/flipsicolor-site/

## What is FlipsiColor?

FlipsiColor is a free, open-source photo and video editor (GPL-3.0) for Windows and Linux that corrects, restores and enhances images using AI models running entirely on your own computer: RAW support (CR2, CR3, NEF, ARW, DNG), Lensfun lens correction, frame-accurate video grading with preserved audio, RealESRGAN upscaling up to 4x, CodeFormer face restoration and automatic low-light enhancement with 11 classic algorithms. All AI models run offline on the user's own hardware — no upload, no account, no subscription. Source code: https://github.com/TechFlipsi/FlipsiColor
